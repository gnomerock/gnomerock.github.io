# Payment Report

A utility for extracting payment reports from **Thai banks** using the Gmail API. This tool automates the process of collecting and organizing bank notification emails into structured payment reports.

## Features

- Gmail API integration
- Thai bank email parsing
- Automated report generation

- **Language**: JavaScript
