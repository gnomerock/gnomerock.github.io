# Android Capture Server

A **packet capture service** that provides network traffic analysis for Android devices. The server acts as a proxy to capture and analyze network packets from mobile applications.

## Features

- Proxy-based packet capture
- Android device support
- Network traffic analysis
- Security auditing tool

## Tech Stack

- **Language**: Python
- **Type**: Security/Networking
